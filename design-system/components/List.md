# List

A vertical index of rows with text and a leading or trailing element (M3).

- `List` is a `<ul>`; fill it with `Leafy.ListItem`: `headline` (required), `supportingText`, `overline`, `leading` (icon name, `Leafy.Avatar`, image), `trailing` (icon name or node; with `trailingIsText` a short label), `onClick`, `selected`.
- Heights follow the line count: 56px, 72px, 88px.
- For rows of comparable values with columns, use DataTable.
