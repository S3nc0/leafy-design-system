# Radio

Selects exactly one option from a small set shown all at once.

- Provide `label`, a shared `name`, and `checked` + `onChange` or `defaultChecked`. Wrap the set in `role="radiogroup"` with an `aria-label`.
- Two to seven options; for more use Select. Preselect one when a choice is required.
- 18px ring, 1px `on-surface`, 8px `primary` dot when selected.

## Sound

Plays `select` when a person chooses it.
